# 自我提升体系：GDPx 六步法的无梯度等价落地

> 背景：SemiAnalysis 2026-11 发布的 GDPx 基准（11 个 agentic 域）衡量前沿模型也不过 12 分，
> 且按 $50/任务计价——大多数 agent 团队跑不起。本文是它的平民等价物，
> 在无梯度训练（无权重更新权限）的约束下，用「经验回灌」近似 RL 的强化环节。

## 六步映射

| 原方案 | 无梯度等价物 |
|---|---|
| 选一个子域 | 从自身事故库统计最高频失败类（如：验证类 33%） |
| GDPx 跑 20-50 条 | 自建评测集：从事故库出题，每题带标准解与判分点 |
| 失败四分类 | 规划/工具/验证/成本，逐案编码（见 failure-taxonomy.md） |
| 最高频类构造 20 条训练任务 | 每题结构：场景 + 陷阱 + 标准解动作链 + 反思点 + 血案出处 |
| 少样本 + 反思式监督 | 评测前注入训练集；作答闭卷（先写答案再看标准解） |
| Agentic RL 强化成功轨迹 | 全对知识点内化（不再注入）；错题升级为常驻规则或 skill 沉淀 |
| 固定评测集每周回归 | 定时任务抽 5 题闭卷作答 + 物证判分 + 纵向对比留痕 |

## 题目设计要点

1. **陷阱真实**：每题对应一个真实踩过的坑，不要编造理论上可能的错
2. **判分物证化**：正确答案必须是可核对的动作链（「跑什么命令、看什么输出」），
   而非「应该多小心」式的态度描述
3. **分类标签化**：每题标注陷阱子类（显示层不可信/自评不可信/假成功检测/实验归因/物证断言），
   便于按类统计薄弱面
4. **带出处**：每题挂血案编号，防止「这条是不是真实教训」的争议

## 回归闭环

```
周日 20:00 定时触发 → 抽 5 题 → 写 pending 任务单 → 通知运营者
agent 醒来 → 见 pending 先闭卷作答 → 按 gold 物证判分 → 成绩落盘
  ├─ 全对 → 该知识点视为已内化，不再注入（省上下文预算）
  ├─ 错题 → 升级常驻规则 / 补进对应知识模块，并标注到题
  └─ 连续两周同题错 → 升级为会话启动强制注入项
```

## 防作弊条款（重要）

- 作答前禁读标准解；判分只认物证
- 抽题后不许重抽；成绩只许如实报告，不许静默改题
- 定期让运营者抽查判分记录——agent 既是被测又是判卷人时，抽查是唯一防线

## 效果验证

体系的健康度不看「训练了多少题」，看两个纵向指标：
1. 新事故率（每周新增事故数）是否下降
2. 失败分类占比迁移——验证类占比下降说明纪律内化生效
